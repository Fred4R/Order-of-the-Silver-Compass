# Armies

Exact list exports. Do not edit an export to match a later story or a later points schedule. Add a new file if the list changes.

Both lists are default configurations of one company aboard the *True Meridian*. They are not two timelines.

- `FORCE-1985-V946.txt` — Strike Force default (1,985 points).
- `FORCE-3000.txt` — Onslaught default (3,000 points), including House Montfort engines.

No physical miniatures exist yet. These are designs.
